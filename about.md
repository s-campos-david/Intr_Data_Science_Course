I'm David Campos. I spend most of my time working with data, and I started this blog while
going through the Udacity Data Science track as a place to write up what I find.

The idea is simple. I pick a public dataset, ask a few questions I actually want the answer
to, and write up what the data says in plain language. No formulas in the posts. Everything
technical lives in the notebook on GitHub, linked at the bottom of each post.

Code for the posts: [github.com/s-campos-david](https://github.com/s-campos-david)
